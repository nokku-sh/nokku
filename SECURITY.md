# Security

Please do not open a public issue for a suspected vulnerability. Use GitHub's private reporting instead: open this repository's **Security** tab and select **Report a vulnerability**.

Each part has its own policy. It says what is in scope and how to run that part safely.

| Core and web app | [core/SECURITY.md](./core/SECURITY.md)         |
| Daemon           | [daemon/SECURITY.md](./daemon/SECURITY.md)     |
| CLI              | [cli/SECURITY.md](./cli/SECURITY.md)           |
| Shared packages  | [internal/SECURITY.md](./internal/SECURITY.md) |
